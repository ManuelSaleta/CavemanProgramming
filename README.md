# Caveman Programming Repository
- Its sole purpose is to become a reference guide for topics of interests. To learn how to spot, and more importantly apply useful design patterns.
- Specially in the agentic area of coding, staying in coding condition so when the LLM spits code at you, you can... *see sharp*... donthurtme.
- I hope to add more topics here.

## Core Ethos of This Project

> **Demystifying high-brow theory into practical craftsmanship: stripping away intimidation to reveal that advanced patterns are practical engineering plumbing—sharpening an engineer's instincts to truly understand the mechanics beneath modern .NET abstractions rather than treating them as black boxes.**

- **Pragmatism over Pedantry:** Replacing academic jargon and overengineering with mechanical intuition and practical mental models.
- **Idiomatic Alignment:** Proving that design patterns aren't alien concepts—showing how they map naturally and idiomatically to modern C# and .NET.
- **Mastery in the AI Era:** Staying in "coding condition" so you understand how systems actually work under the hood instead of passively accepting generated code.
